# 🦊 GitLab Achievements Pack

Uma coleção de **42 medalhas personalizadas e bem-humoradas** para gamificar a rotina de desenvolvimento, QA, DevOps e onboarding no **GitLab** (inclusive na versão **Free Self-Managed**).

A ideia é simples: transformar aqueles marcos clássicos do dia a dia da engenharia — desde commitar um `.env` sem querer até salvar uma entrega na sexta-feira ou derrubar um banco no teste de carga — em momentos leves de aprendizado, reconhecimento e descompressão para o time.

## 🚀 Como usar no seu GitLab (inclusive Self-Managed Free)

### 1. Cadastro Manual pela Interface
1. Acesse seu **Grupo** no GitLab (Achievements são configurados a nível de grupo).
2. No menu lateral, vá em **Settings > General** e expanda a seção **Achievements** (ou acesse diretamente `https://seu-gitlab.com/groups/SEU-GRUPO/-/achievements`).
3. Clique em **New achievement**, envie a imagem da pasta `/badges`, preencha o título e cole a descrição correspondente.

### 2. Concessão Automática via GraphQL API
Mesmo no tier **Free Self-Managed**, você pode automatizar a entrega de conquistas usando um **Personal Access Token** (com escopo `api` de um usuário Maintainer/Owner do grupo) e a mutation `achievementsAward`:

```bash
curl --request POST \
  --header "PRIVATE-TOKEN: $GITLAB_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{
    "query": "mutation { achievementsAward(input: { achievementId: \"gid://gitlab/Achievements::Achievement/1\", userId: \"gid://gitlab/User/42\" }) { userAchievement { id } errors } }"
  }' \
  "[https://seu-gitlab.com/api/graphql](https://seu-gitlab.com/api/graphql)"
```
